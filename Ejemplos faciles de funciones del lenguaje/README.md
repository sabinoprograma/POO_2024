En esta carpeta tenemos una colección de **apuntes y ejemplos de código Python** enfocados en programación orientada a objetos. Se organiza en dos niveles: archivos sueltos con implementaciones de referencia (herencia, polimorfismo, listas enlazadas, manejo de excepciones y NumPy), y carpetas de ejemplos prácticos que amplían cada uno de esos conceptos — agregación, asociación, composición, herencia simple y múltiple, polimorfismo, listas enlazadas, assert y raise. En conjunto forman un **repositorio de estudio personal** donde cada concepto tiene tanto su plantilla base con un ejemplo de uso concreto para entenderlo en acción.
