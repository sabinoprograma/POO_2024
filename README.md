# POO Python - 2024 - UNSJ

Material completo de la cursada de Programacion Orientada a Objetos en Python. Organizado por unidades tematicas, con ejercicios practicos, evaluaciones y ejemplos de referencia.

## Estructura

* Ejemplos faciles de funciones del lenguaje — snippets y ejemplos minimos de conceptos del lenguaje
* Guias de ejercitacion — guias de practica propuestas durante la cursada
* Miscelanea — material variado sin categoria especifica
* Parciales practicos, practicas operativas y Examenes finales — material de evaluacion
* Unidad 1 UML — modelado con UML
* Unidad 2 Sintaxis, sobrecarga y Numpy — sintaxis POO, sobrecarga y NumPy
* Unidad 3 Relaciones entre clases — herencia, asociacion, agregacion y composicion
* Unidad 4 Interfaces graficas — desarrollo de GUI en Python
* Unidad 5 POO WEB — aplicacion de POO en desarrollo web
